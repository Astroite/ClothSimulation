# GNN v4：表面运动与四拍节点历史

## 冻结契约

本版实现现有 5,294 顶点服装上的端到端验证；不承诺多体型泛化或产品级 60 FPS。
保留旧 TinyHOOD 32×12、20/12/9 输入、30 Hz 推理、240 Hz XPBD、加速度保持与信任限制。
新增分支和权重独立，旧默认算法与用户资产不被替换。

### 身体表面

`BodySurfaceFrame` 提供秒时间戳、稳定 ID、世界米位置、法线和可选下一时刻目标。
三角采样用三角形及重心坐标；胶囊采用绑定空间参数坐标和完整变换，不能每帧重新选择方向基。
身体速度取同一 ID 的连续轨迹；最近身体节点变化不产生新的速度来源。
骨骼只存在于适配层。预处理存储图、静止几何、质量、固定点、表面绑定和资产 SHA-256。
每个资产节点数可不同，但单次运行中的拓扑和稳定 ID 不变。

### 历史

窗口顺序为最旧到最新 `[t-3,t-2,t-1,t]`，每拍 `[dx,dy,dz,nx,ny,nz,valid]` 共 28 维。
布料位移为修正后速度乘 1/30；身体位移为同一表面点的当前位置减上一推理时刻位置。
运动与法线使用旧 node normalizer 的对应通道；valid 不归一化。
首次身体位移为零；缺拍复制首个样本但 valid=0，真实当前样本 valid=1。
current-only 对照把当前样本复制到四槽，架构与参数量完全相同。
时间编码器为 Linear(28,32) → ReLU → Linear(32,32)，最后一层全零初始化。
时间编码结果加到旧节点 latent，再执行原 12 个块；无 RNN 隐状态、无跨帧边记忆。

### 输出和状态

旧 decoder 输出 d 的单位为每 30 Hz 拍的加速度位移，a_net=900*d。
XPBD 使用 a=g+strength*confidence*(a_net-g)，不得重复重力或直接覆盖位置。
历史仅在真实推理事件采集；检查点保存全部历史、游标、有效长度、时间计数、身体前一拍和保持加速度。
重置/资产切换清历史；时间跳转恢复相应检查点并重放。新格式拒绝不匹配契约。

## 训练与门禁

训练 idle/walk/run/sprint/jump 的 0.75/1/1.5× 和 root-motion 两模式；验证 turn；最终测试完整 complex。
连续序列及所有同源变体不可跨训练/验证划分；normalizer 只用训练集。
高预算纯 XPBD 为 480 Hz ×8 结构迭代；抽样由同一起态运行 960 Hz 对照，并检验穿透、退化及收敛。
参考未通过时停止质量训练，仍可完成接口验证；不得用坏参考宣称时序有收益。
PyTorch 训练参考需覆盖当前求解顺序，离散候选选择无梯度，连续约束投影保留梯度。
先旧权重初始化与蒸馏，再通过实际耦合展开位置/速度/形变损失；完整加速度不能直接当额外外力标签。
batch=1，展开四拍，梯度检查点，可恢复；先一个种子全链路，再三个种子正式消融。

## 验收

- 老模型、新结构 current-only、四拍模型使用相同数据/预算；后两者参数量一致。
- 特征及 decoder 对拍 atol=1e-5, rtol=1e-4；真实物理单步最大位置误差 1e-4 m。
- 检查稳定采样、换近邻、节点置换、变节点数、缺拍、暂停、重置、跳转、检查点重放与算法切换。
- 旧 CTest/GPU/GNN 测试回归；同 GPU 检查点重放应精确一致；零强度等于纯 XPBD。
- 完整 complex 三循环、七动作、固定扰动逐帧统计；不以末帧有限性替代质量验收。
- 三种子位置/速度综合误差降低至少10%，穿透/退化不恶化超过5%；近零基线使用数值容差。
- 推理 p95 额外成本目标不超过25%，同时记录完整帧时间/显存/设备负载。
- 未达质量门禁时交付实验模式及负结果，保留旧默认模式；工程通过与质量收益分开报告。
