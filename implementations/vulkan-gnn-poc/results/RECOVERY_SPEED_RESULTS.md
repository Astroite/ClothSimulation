# S10 / S10b 实测结果：恢复力与速度断裂点

执行 [`plans/gnn/gnn-xpbd-v2.md`](../../../plans/gnn/gnn-xpbd-v2.md) §8.0 的 (a) 与 (b) ——
**第一次按项目自己的价值主张（而非"对 HOOD 的距离"）来测量三个分支。**
工具 [`tools/recovery_probe.py`](../tools/recovery_probe.py)，测试机 RTX 4060 Ti，
`student32x12_r1`，120 步，A/C 用 k=128、B 用 k=228（等预算，见 §0）。

## 结论摘要

1. **我预先写死的零空间预测被推翻。** 纯 XPBD **能**从精确等距的折叠中恢复（半衰期 16–30 步）。
   §1 给出机制错在哪。
2. **痛点 2（高速）被干净地量化了**，而且**功劳归 XPBD，不归网络**：动画放到 2× 速度，
   纯 GNN 的 edge P95 峰值恶化 **7.1×**（1.967 → 13.958），混合只恶化 1.29×。
3. **痛点 3（坏 pose 恢复）的真实收益是"最坏情况有界"**：`tpose` 上纯 GNN 被扰动后恶化
   **12.2×**（1.345 → 16.371），混合 1.37×。**混合受损后的最坏状态（1.768）比纯 XPBD
   未受损的最好状态（3.667）还好。**
4. **但混合不是免疫的**：在本来就最快的 `ch10032_sprint` 上放到 2×，混合的峰值 9.076 差于
   纯 XPBD 的 2.939。它赢在**动画停下后能松回去**（末态 1.536 对 2.374）。
5. **轨迹遗忘度是较弱的仪表**，pose 质量列才是可报的（§4）。

> **口径**：下表的 `edgeMAX` 是**观察窗内 edge P95 的最大值**，`edgeEnd` 是末步值。
> 只用末步值会被 settle 欺骗 —— 137 帧的片段放到 3× 在第 46 步就播完，其后是静态松弛。
> **两列都报**是因为它们分别回答"峰值多高"和"停下后能否松回"。

## 〇、B 支这次拿到了等预算

§0.3 记录了 G0 的 B 支只有 56% 的预算。本轮按实测单价补上：

```
C = GNN 0.924 ms + XPBD k=128 × 9.437 µs = 2.154 ms
B = 2.154 ms / 9.437 µs ≈ 228 次投影      ← --b-iterations 228
```

**仍未补的一项：substep。** `project()` 是单个 Δt 下迭代 k 次，本轮 B 是 `1 步 × 228 次
Jacobi`。这是 **S10c**，未做。但本文的中心结论不依赖它：substep 改的是迭代调度，
而 §1 的等距损伤与 §2 的速度轴测的都不是调度能左右的量 —— 事实上 B 在本轮**已经赢了**
若干项，所以给它更多预算只会强化下面的结论，不会推翻。

## 一、❌ 零空间预测被推翻（本轮最重要的一条）

### 预测与实测

`plans/gnn/gnn-xpbd-v2.md` §0.3（2026-08-20 上午写入）的论证是：Jᵀ 的零空间包含所有等距形变，
折叠/缠绕/穿模全是等距的，所以**距离约束对坏 pose 结构性失明**，纯 XPBD 不可能恢复。
预先写死的判据是"`fold`/`penetrate` 下 B 不恢复而 A/C 恢复"。

实测（`ch10032_tpose`，excess ratio = 末超出量/初超出量，越小越好；half = 超出量半衰期步数）：

| 损伤 | 等距误差 | A 纯 GNN | **B 纯 XPBD** | C 混合 |
| --- | ---: | ---: | ---: | ---: |
| `stretch`（可见，正对照） | — | 15.99 | **0.30**（22 步） | 0.55（66 步） |
| `fold`（**精确等距**） | 2e-07 | 3.13 | **0.29**（30 步） | 0.00（29 步） |
| `penetrate`（**精确等距**） | 1e-08 | 4.35 | **0.24**（16 步） | 0.53 |

**B 从三种损伤全部恢复，A 一种都不恢复。判据被违反，预测错。**

把补丁翻转的程度看得更清楚一点 —— 新增翻面比例 Δflip（`fold`，tpose）：

| A 纯 GNN | B 纯 XPBD | C 混合 |
| ---: | ---: | ---: |
| **+0.122** | **+0.019** | +0.096 |

**纯 XPBD 把翻折的补丁掰回来掰得最好。** 这与我的论证正好相反。

### 论证错在哪

零空间那句话本身是对的，但它成立的范围比我用的窄：

> **"单次投影表达不了某个位移" ≠ "该状态是整个闭环的不动点"。**

实测：BFS 测地补丁（200 顶点）的刚体半周旋转确实精确保持了**内部**所有距离（等距误差 2e-7），
但它**违反了边界环上约 10% 的边**（实测 106 条边界边对 1088 条内部边）。而闭环里还有重力、
接触投影、以及 228 次 sweep × 30 步的传播。这些合起来足以把折叠解开。

**教训**：零空间是关于**一次线性化投影的像空间**的陈述。要从它推出动力系统的性质，
必须再证明"违反集为空"，而等距形变的违反集不是空的 —— 它是补丁的边界。
**这一步我跳过了。**

### 后果

- `plans/gnn/gnn-xpbd-v2.md` §0.3 的"零空间论证：为什么这是痛点 3 的机制"**撤回**；
- §5.1 里 `test_warmstart_discards_a_null_space_displacement` 的结论**回退为原状**：
  它说明 warm start 无用，不说明 XPBD 恢复不了坏 pose；
- **分工表的归属需要反过来写**，见 §3。

## 二、痛点 2：速度断裂点

`--frame-scales` 抽帧得到精确时间缩放，**`timestep` 刻意不缩放** —— 否则等比例给每个求解器更多
预算，什么也测不出来。干净 rollout（无损伤）的 `edgeMAX`：

### `hml_001962`（137 帧，1× 时片段不会播完）

| 分支 | 1× | 2× | 3× | 最坏/1× |
| --- | ---: | ---: | ---: | ---: |
| A 纯 GNN | 1.967 | **13.958** | **14.814** | **7.5×** |
| B 纯 XPBD | 3.382 | 4.054 | 3.672 | 1.20× |
| **C 混合** | **1.533** | **1.974** | **2.687** | **1.75×** |

**这就是痛点 2，被复现成一条连续的压力轴而不是一个是非题。** 三条读法：

1. **纯 GNN 在 2× 就崩**（1.967 → 13.958）。学生只在 1× 的 teacher 轨迹上训练过，
   2× 的身体位移是分布外的，它无界外推。
2. **纯 XPBD 几乎不受速度影响**（1.20×）—— 它没有要外推的东西。但它在任何速度下的绝对质量
   都差 2.2×（3.382 对 C 的 1.533）。
3. **混合在每一档都最好，且退化平缓。C 在 3×（2.687）仍好于 B 在 1×（3.382）。**

### `ch10032_sprint`（62 帧，本来就是最快的动作）—— 如实记录的反例

| 分支 | 1× max / end | 2× max / end | 3× max / end |
| --- | ---: | ---: | ---: |
| A 纯 GNN | 7.443 / 6.377 | 11.499 / 11.499 | 9.443 / 7.965 |
| B 纯 XPBD | **2.874** / 2.753 | **2.939** / 2.374 | **4.432** / 3.102 |
| C 混合 | 2.636 / **1.325** | 9.076 / **1.536** | 7.359 / **1.451** |

**混合不是免疫的**：sprint 放到 2×，C 的峰值 9.076 明显差于 B 的 2.939。

但 `edgeEnd` 列显示了另一件事 —— **动画停下后谁能松回去**：

| 分支 | sprint 2× 峰值 → 末态 |
| --- | --- |
| A | 11.499 → 11.499（**完全不松**） |
| B | 2.939 → 2.374 |
| **C** | 9.076 → **1.536**（松回到接近 1× 的水平） |

所以在极端运动下的正确说法是：**B 峰值最好，C 末态最好，A 两样都不行。**
C 的瞬时峰值是一个具体的、已定位的缺陷 —— 它很可能正是 **S9（面积/二面角约束）**要修的，
因为 `XPBD_VULKAN_RESULTS.md` §2 已经测到 sprint 上退化三角形恶化 5.4×，而距离约束管不住
三角形压平。

## 三、痛点 3：真实收益是"最坏情况有界"

`ch10032_tpose`，`edgeMAX`，干净对最坏受损：

| 分支 | 干净 | 最坏受损 | 恶化 |
| --- | ---: | ---: | ---: |
| A 纯 GNN | 1.345 | **16.371**（`stretch`） | **12.2×** |
| B 纯 XPBD | 3.667 | 4.439 | 1.21× |
| **C 混合** | **1.291** | **1.768** | **1.37×** |

> **C 受损后的最坏状态（1.768）比 B 未受损的最好状态（3.667）还好。**

`hml_001962` 上同样的表（该场景学生在分布内，A 不崩）：

| 分支 | 干净 | 最坏受损 | 恶化 |
| --- | ---: | ---: | ---: |
| A | 1.987 | 2.397 | 1.21× |
| B | 3.386 | 3.787 | 1.12× |
| **C** | **1.477** | **1.767** | **1.20×** |

**只有 A 可以被一次扰动推向灾难**（12.2×）。把 XPBD 放进闭环之后最坏情况被夹住了 ——
这是纯粹的"保险"价值，与"更接近 teacher"无关。

### 修正后的分工（归属与我原来写的相反）

| | ML 前置驱动 | XPBD 后置 |
| --- | --- | --- |
| **提供** | **正确的形状与动力学** —— C 1.291 / 1.533 对 B 3.667 / 3.382 | **鲁棒性** —— 抗高速（1.20×）、抗损伤（1.21×）、最坏情况有界、动画停后能松回 |
| **盲点** | **高速下无界外推**（2× → 13.958）、**放大损伤**（12.2×） | **形状错**（差 2.2–2.8×）；极端运动下峰值仍会破（S9） |
| **逐资产人工成本** | 0 | 0 |

两半的盲点确实互补，`C ≪ min(A, B)` 也确实有机制 —— **但机制是"网络给形状、约束给鲁棒性"，
不是我原先写的"网络给流形回归、约束给几何界"。**

## 四、⚠️ 轨迹遗忘度是较弱的仪表

`forget(t) = RMS‖x_受损(t) − x_干净(t)‖`，减去控制组（未受损重跑）曲线后得 excess。
它在两处不可靠：

1. **与 pose 质量矛盾。** `hml_001962` 上 C 的 `fold` excess ratio 是 1.15（读起来像"没恢复"），
   而它的 `edgeMAX` 是 1.491 对干净 1.477 —— pose 完全正常。布料有很多个同样合理的垂坠，
   落到**另一个**合理褶皱上会被轨迹同一性指标判为失败。
2. **跨进程噪声大。** 同一配置（C / tpose / `penetrate`）在两个进程里得到 **1.03 与 0.53**。
   这与 `GATE_G0_RESULTS.md` §8 已确立的跨进程噪声是同一件事。**所以约 2× 以内的 ratio 差异
   不可分辨。**

**因此本文所有可报结论都取自 pose 质量列**（`edgeMAX` / `edgeEnd`），
它们的效应量是 7×–12×，远在噪声之上。excess ratio 只用于 §1 那个**定性**判据
（B 恢复 / A 不恢复），那里的差距是 0.24–0.30 对 3.13–15.99。

还有一个口径问题：`flipped` 由 `curve_point` 对 **`cloth_rest` 法向**计算，而 §2.3 已证 rest
在真实服装上不是可用基准 —— 干净 rollout 的 flip 就有 0.30–0.65。**所以 flip 只能用同一分支
干净对受损的差值（Δflip），不能当绝对量读。**

## 五、仪表本身踩到的四个坑（都已写成断言）

`tests/test_recovery_probe.py`（9 项）把下面每一条固定住，因为它们都会**静默地**让实验测错东西：

1. **补丁必须沿网格边生长。** 欧氏近邻球会跨过腿抓到服装另一侧：n=200 时 flatness（σ₃/σ₁）
   **0.72**、边界边 170 对内部 1040；BFS 测地补丁是 **0.19** / 106 对 1088。
2. **`fold` 必须是刚体半周旋转，不能是平面反射。** 反射要求补丁近平面才算折叠，而实测不平面，
   于是它破坏的边比 `stretch` 还多（RMS **0.189 对 0.025**）—— 那测的根本不是零空间。
   半周旋转 `R(v) = 2(v·u)u − v` 是行列式 +1 的正交变换，**对任何补丁形状都精确等距**。
3. **等距误差必须在 float64 下用显式差值算。** `torch.cdist` 展开成 `‖a‖²+‖b‖²−2a·b`，
   float32 下米级坐标损失约 **5e-4 m**，比被测量本身还大 —— 它把一个精确等距报成 4.9e-4 违反。
4. **穿模比例对深度非单调。** 同一补丁向体内平移：0.05 m → 4.5%、0.08 → 20.0%、
   **0.12 → 28.5%**、0.16 → 11.0%、0.25 → **1.0%**。深到一定程度就**从腿另一侧穿出去了**，
   最近代理换成对侧表面，判据又说它合法。

第 4 条不只是仪表问题，它是一条关于求解器的结论：

> `real_scene/xpbd.py::_resolve_contacts` 与 `hood_xpbd.comp` 用的**正是**同一个最近代理半平面
> 判据，**所以隧穿过肢体的顶点对求解器同样是合法的**。绝对穿模数字必须等 S5。

## 六、本轮没做

- **S10c 强 XPBD 对照的 substep 部分**（§0）。`plans/gnn/gnn-xpbd-v2.md` §8.3 写了却从未执行。

  （折叠 30°/90°/180°、穿入 0.04/0.08/0.12 m），那才能区分"扰动可恢复"与"分布外不可恢复"。
  这是本实验最值得做的下一步。

- **绝对穿模指标**（S5）。`pierce` 列只覆盖带 world edge 的顶点，且对隧穿失明。
