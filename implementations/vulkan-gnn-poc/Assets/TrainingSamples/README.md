# Curated motion samples

This is a deliberately small motion set for bringing an animated body and a
custom garment into the Vulkan cloth PoC. It is not a training corpus.

| Motion | Coverage | Source FPS | Duration |
| --- | --- | ---: | ---: |
| `hml_001962` | forward walk, turn, stop | 100 | 4.53 s |
| `hml_009402` | walk, right spin, return | 100 | 4.40 s |
| `hml_000295` | squat / sustained knee bend | 100 | 4.35 s |
| `hml_001977` | single left-leg kick | 120 | 3.41 s |
| `hml_002926` | squat, vertical jump, landing | 120 | 4.01 s |
| `hml_011319` | full-body spin with extended arms | 120 | 4.74 s |

Each motion directory contains:

- `*_raw.npz`: the master source-rate segment. Use this for any future
  resampling or training-data preparation.
- `*_60fps.npz`: a convenience preview generated by linear interpolation of
  axis-angle values. The source export marks it `trusted=false`; do not treat
  it as rotation-correct ground truth.
- `*.fbx`: a validated animated SMPL body-22 skeleton with 22 bones. It has no
  body mesh and retains the source rate (100 or 120 fps).

`manifest.json` is authoritative for captions, frame counts, validation
results, relative paths, and SHA-256 hashes. Character and garment assets are
described one directory above in `Assets/README.md`.

To reconstruct this subset from the existing local export:

```powershell
& .\.venv\Scripts\python.exe tools\import_motion_samples.py `
  --source-root 'F:\Projects\Anim'
```

Pass `--overwrite` only when intentionally refreshing files from the source
dataset. The data terms in `Assets/README.md` apply.
