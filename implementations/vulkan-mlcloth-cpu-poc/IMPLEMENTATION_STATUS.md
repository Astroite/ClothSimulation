# Demo 重构实施状态

目标：本机 i7-13700KF / RTX 4060 Ti，1080p 三角色稳定 60 FPS。
状态：开发中，尚未完成用户方案的最终质量、性能与交付验收。

## 已落地

- GNN + XPBD 已接入第三角色的运行时算法选择：TinyHOOD 30 Hz 加速度与持续 XPBD 状态结合；点 BVH、确定性反向 CSR、子步检查点及失败恢复已验证。本轮没有迁移角色资源或开展全量性能验收，参见 [GNN_PORT.md](GNN_PORT.md)。

- 完整骨架与 45 驱动骨骼分离、固定世界方向的实例偏移、独立动画 / 物理 / 推理时序。
- 七个动作导出及七个可编辑 Blender 动作；原始 F 盘资源保留。短循环修正 FBX 末帧时长，跳跃和往返转身合成。
- Blender 独立求值参照：七个动作各三个采样帧，验证 1,015 根实际骨骼和身体蒙皮；身体最大偏差约 0.014 mm。虚拟 UE 根节点单独处理。
- 纯 ML、纯物理和持续状态混合分支；240 Hz 小步 CPU / Vulkan 求解，粗层引导、结构着色、动态接触 gather。
- 身体扫掠接触、嵌入恢复、摩擦；VF / EE 自碰撞及静止测地邻域排除。
- 修复固定边接触的微小负重心权重放大、边缘接触方向、交叉边法线不稳定和零权重接触影响 gather 计数的问题。
- 检查点、分帧确定性重放、同步 / 解除同步、陈旧推理结果隔离、设置持久化。
- 身体 / 头部原始颜色贴图、真实深度阴影、灰模、基础镜头和运行时 UI。
- 无参数 `run.ps1`、双击 `start_demo.cmd`；旧 PoC 文档和参数脚本归档。
- 构建入口编译并验证 SPIR-V，避免运行旧的预编译求解器。
- 腿部 10 节胶囊 + 肩臂 / 臀部 STM + 腹部封闭过渡，已作为开发版默认资源；可在 UI 切换表示及查看透视轮廓。
- 物理布料使用精确身体三角形表面绑定；21 个独立姿态中冲突的 23 个硬绑定已释放，当前 409 个绑定。
- 可编辑的 `C10032_HybridCollision.blend`：STM 与胶囊均完整绑定；七动作 21 姿态的 Blender 独立蒙皮 / 端点检查通过，误差远低于 1 mm。

## 最新验证与限制

- 最近完整 CTest：13 项通过；CPU 物理测试包含 34 个用例。GPU 合成检查 88 项通过，包含高速胶囊穿越、首次身体碰撞、伪法线、接触感知粗层引导、自碰撞溢出回退与重复性。
- 完整 5,294 顶点单步 CPU / GPU 对照已通过一个预热状态，结构 / 身体 / 自碰撞误差均小于 20 μm；静止身体下的检查点恢复重放 48 个接触子步误差为零。这不代表长期质量达标。
- GPU 候选缓存的进入接触、检查点重放及溢出回退测试通过；真实角色实测未获得收益，默认关闭。身体最近三角形上界与运动距离排除已优化，并通过单步对照。
- 目前实测仍未达到 60 FPS。固定时间步诊断不可替代实时 10 分钟测试。
- 原碰撞代理缺少臀部和腿部，已替换为用户建议的混合表示。混合表示仍与身体轮廓存在差异，腋下穿透、局部拉伸和细节仍不足；装饰显示网格尚未接入。
- 固定时间步测试：六个短动作分别连续 20 圈，复杂动作连续 3 圈，均到达结束时间且终态数据有限。报告在 `.work/demo/rollouts-20260907-161741`。终态检查不能替代逐段可见穿模和全过程质量采样。
- 该轮帧时间 p95：待机 25.5、走 31.8、跑 29.0、冲刺 68.8、跳 56.6、转身 30.8、复杂动作 35.1 ms；同步测试、固定显示步长，不能作为实时性能验收。接触质量和 60 FPS 均未达标。
- 长循环之后修复了凹角接触：一次扫掠平面投影后，对仍在身体内部的接触粒子进行有限次数的残留检查，随后复核胶囊重叠。CPU / GPU 合成凹角测试通过；不能用之前的长循环报告为后续变更直接签署验收。
- 新增身体范围自动取景、清晰字体、碰撞轮廓，以及 B / C 分别计时的 GPU 子步和独立渲染计时；尚未完成所有 UI 控件的真实交互验收。
- 后续将身体 / 自碰撞的扫掠上界改为相对运动上界，消除共同根位移造成的额外搜索。共同平移测试、合成接触测试和完整网格单步检查通过。
- **性能环境未隔离**：2026-09-07 17:03 本轮 Demo 已退出且没有残留 `mlclothcpu` 进程时，`nvidia-smi` 仍报告 GPU 96% 占用、约 8.2 GB 显存使用。上面的时序是显卡被共用时的观测，不能直接判断空闲 GPU 下是否满足 60 FPS。需要暂停其他 GPU 工作后重新测量，不能据此宣称算法已达标或独占性能不达标。

用户选择先继续算法与展示，性能稍后复测。因此未继续进行 10 分钟性能验收，也未停止其他 GPU 程序。
