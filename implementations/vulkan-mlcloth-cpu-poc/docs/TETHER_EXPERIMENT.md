# 整体伸长限制实验

2026-09-07。按用户安排，本阶段只比较算法和显示效果，性能验收后移。

CPU 和 Vulkan 新增可选的单向长距离约束，参考 [Long Range Attachments](https://matthias-research.github.io/pages/publications/sca2012cloth.pdf)。沿固定布料网格的边长预计算最短路径；每个自由顶点最多选择四个不同的相连绑定区域，每个区域取最近的绑定点。没有绑定点的连通布片不生成约束。边路径长度是保守近似，未冒充精确曲面测地线。

每次结构迭代后，以当前身体蒙皮绑定目标为锚点，仅在超过路径长度乘以允许系数时修正。多个锚点的修正取平均；没有超过上限的布料可以继续折叠。CPU/GPU 都使用一个顶点一个写入者，不读取其他自由粒子的同时写入结果。B、C 使用完全相同的表和参数，A 不使用此算法。

UI：Settings → Physics parameters → Limit global stretching。允许系数可在 1.00–1.30 之间调整，默认 1.05。改变设置会在帧边界重建状态和检查点。**开关默认关闭**。

## 验证

- CPU 28 项测试通过，新增折叠余量、无绑定连通区域、绑定区域去重、当前动画锚点、关闭开关及参数合法性检查。

这些验证只证明实现约定和短片段表现，不表示整体 Demo 已满足穿透或性能目标。
