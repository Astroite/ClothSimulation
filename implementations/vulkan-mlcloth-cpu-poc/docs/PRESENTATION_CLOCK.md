# 身体与布料的统一显示时刻

物理状态仍按固定子步推进。播放时，渲染在最近两个物理状态之间插值，身体骨架采样、ML 布料、XPBD 布料、镜头范围和碰撞诊断采用同一个显示时刻。在默认 240 Hz 下，相对推进中的播放时钟保留一个子步（约 4.17 ms）的插值缓冲。

物理状态、速度、ML 时序历史不被显示插值改写。Vulkan 将当前和前一个物理位置复制到当前渲染帧的 GPU 缓冲，顶点着色器插值位置，法线着色器根据同一组插值顶点计算法线。正常播放不回读布料网格。纯 ML 仍只显示网络输出的坐标转换与插值。

暂停和独立暂停显示精确的当前状态。时间轴恢复会使旧插值区间失效；GPU 重置及检查点恢复同时重建位置历史。恢复播放后，在得到下一个物理状态前保持当前画面，避免短暂回退。

验证入口：

```powershell
./run.ps1 -ValidatePresentation
```

此入口以 1/144 秒的显示步长运行 180 帧，验证非整数物理子步比。仅验证时读取渲染端点和法线，输出 `.work/demo/presentation-validation.json`，失败时脚本返回错误。另由 `demo_session_tests` 覆盖统一显示时间、固定展位偏移、独立暂停、暂停恢复、精确检查点跳转和零时刻恢复。

首轮 Vulkan 验证的三个角色插值系数均为 1/3，显示时间均为 1.238888889 秒，物理时间均为 1.241666667 秒；插值法线与 CPU 参照的最大向量误差小于 5e-7。该检查不代替 UI 点击验收、连续穿透测量或性能验收。
