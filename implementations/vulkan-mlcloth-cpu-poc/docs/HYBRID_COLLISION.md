# 胶囊与 STM 混合碰撞

当前开发版使用用户建议的区域混合方案。纯 XPBD 和 MLCloth＋XPBD 共用碰撞数据；纯 MLCloth 仍直接显示模型输出，碰撞轮廓仅供参照。

## 资产

- 原始 STM：`F:/ArtWorks/Cloth/CH/C10032_ClothCollision_STM_ShoulderHips_800.fbx`，保持原文件不变，导出报告记录 SHA-256。
- STM 覆盖肩颈、双臂、臀部和膝上大腿，并以身体代理的腹部片段进行封闭布尔连接。输出为 1,719 顶点 / 3,434 三角形，按边计数验证封闭。
- 左右腿各 5 节胶囊：2 节大腿、3 节小腿；相邻段重叠，骨骼驱动使用完整骨架的 Hip / Knee。半径按身体表面拟合，单位为米，端点存为骨骼局部厘米。
- 输出：`collision-hybrid.dmp`、`leg-capsules.dmp`、`collision-hybrid.json` 和 `C10032_HybridCollision.blend`。Blender 中的 STM 与胶囊均有完整骨架绑定。
- 物理布料改用身体三角形表面绑定：分别蒙皮三个身体顶点，再以重心位置及切线空间偏移生成绑定目标。离线样本中与其他身体区域冲突的 23 个硬绑定已释放，当前 409 个硬绑定。

## 求解与运行时

所有碰撞数据与布料处于同一惯性坐标系，每个物理子步更新。胶囊保存前后端点，处理快速粒子穿越和胶囊扫掠；初始嵌入恢复抑制虚假的推出速度，摩擦以碰撞表面的相对速度计算。

对一次扫掠平面投影后仍处于凹角内部的接触粒子，CPU / GPU 都补做最多两轮残留检查，并再次处理腿部胶囊重叠。增加了封闭 L 形凹角的高速穿越回归，防止只满足其中一个面的接触条件。

CPU 是独立标量参照，Vulkan 使用同样的输入与约束。胶囊端点与 STM 顶点打包在已有设备缓冲中，正常播放不读取整张布料网格。同步时 B / C 复用同一时刻的身体蒙皮和 GPU 碰撞输入，物理状态保持独立。

身体 BVH 使用上一子步最近三角形重新计算搜索上界，并以运动距离上界排除不可能的扫掠接触；完整候选遍历仍保留。实验性的自碰撞候选缓存目前关闭，其角色实测没有收益。

扫掠距离上界以相对运动计算：顶点—面与胶囊使用相对粒子的端点位移，边—边使用移除共同平移后的两条边的位移上界。共同根运动不会额外放大上界；高速相对接触与共同平移不变性有独立回归测试。

设置可切换混合、仅 STM、仅腿部胶囊。后两者用于诊断，会缺少相应身体区域的碰撞。切换通过安全帧边界重新预热和重建检查点。青色 / 橙色线框分别表示 STM / 胶囊；透视叠加不表示可见面的深度结果。

## 重建与验证

```powershell
./prepare_demo.ps1 -CollisionOnly
./bootstrap.ps1 -SkipFetch
./tools/build-with-vs.cmd
./run.ps1 -Frames 2 -ValidateGpu -ValidateAsset
./tools/validate_demo_rollouts.ps1
```

`prepare_demo.ps1` 自动执行封闭身体代理、表面绑定、混合碰撞烘焙和独立 Blender 检查。旧上身 STM 的清单保存在 `demo-original-stm.json`，完整身体代理保留为几何参照。

验证包括：高速穿越、移动胶囊、初始嵌入恢复、STM 与胶囊同时上传、同步设备缓冲复用，以及完整 5,294 顶点的单步 CPU / GPU 对照。Blender 以七个动作的 21 个独立姿态检查编辑文件，STM 与胶囊端点误差均远低于 1 mm。

## 尚未通过的标准

当前方案仍是开发版。单轮走路的身体穿透有所改善，但冲刺、跳跃仍有腋下穿透和局部过度拉伸。原代理与身体几何也存在偏差，封闭拓扑不等于动态姿态无自交。骨骼 / 蒙皮变换误差通过不代表碰撞质量通过。

`collision-hybrid-fit.dmp` 和 `collision-regional.dmp` 是额外的贴合 / 高细节区域代理实验，未替换默认资产。更密的代理在部分混合模式样本中有改善，但纯 XPBD 仍未达标，因此没有按单帧最优值宣布整体改善。

固定时间步循环可检查能否完整播放及终态有限性；终态快照无法覆盖途中全部可见问题。实时帧时间仍高于目标，不能宣称已达到 1080p 三角色 60 FPS。后续需要继续校准接触与约束、逐段审查，并完成同步 / 解除同步各 10 分钟的实时测试。

本轮测量还存在明确的显卡争用：Demo 退出后，`nvidia-smi` 仍报告约 96% GPU 占用。已有帧时间不能作为空闲显卡性能结论；待其他 GPU 工作暂停后复测。布料几何误差和合成正确性测试不因此视为通过最终质量验收。
